# VYRA AI - Conversational Commerce Assistant

![VYRA Branding](https://grainy-gradients.vercel.app/noise.svg)

VYRA is a premium, AI-powered conversational commerce assistant for India. It enables users to order food, groceries, and essential services through natural language conversations on WhatsApp, powered by advanced LLMs and integrated directly with India's leading commerce APIs.

## 🚀 Vision
To build the "Operating System for Commerce" in India, bridging the gap between millions of users on WhatsApp and the complex ecosystem of hyper-local logistics and inventory.

## 🛠 Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Outfit & Inter
